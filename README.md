
# TaskText — Staging Skeleton

Minimal Next.js App Router project to verify Vercel + domain + SSL + webhooks.

## Routes
- `/` — landing stub
- `/api/sms` — Twilio webhook placeholder (accepts form-encoded or JSON)
- `/api/stripe` — Stripe webhook placeholder
- `/api/postmark` — Postmark webhook placeholder

## Deploy
- Upload these files to your GitHub repo branch (e.g., `tasktext-staging`).
- Vercel will auto-deploy on push.
